# きょーてー君 予想ナレッジベース

> 予想するときの判断基準をまとめたノート。数値は集計元や期間で数ポイント変わる「目安」です。
> 作成日: 2026-10-08

---

## 0. 大前提

- 6艇立て。3連単は **120通り**、3連複は20通り、2連単は30通り。
- 払戻率は **75%**（控除率25%）。適当に全部買えば、長期的には25%負ける。
  → 「当てる」だけでなく **期待値（確率 × オッズ）が1を超える買い目を選ぶ** ことが本質。
- 着順を決めるのはだいたい **1周目1マーク**。予想は「1マークで誰が先に回るか」を当てる作業。

|---|---|---|---|---|

| 2 | 15.2% | 39.6% | 58.2% | 差し約65%／まくり約24% |
| 3 | 12.9% | 33.6% | 53.3% | まくり約38%／まくり差し約38% |

- 1コースは **8割で3着以内**。「1号艇が3着以内」は大半のレースで前提にしてよい。
- 6コースの1着は約50レースに1回。6号艇を1着に置くのは、根拠がある時だけ。
- 4コース（カド）は数字以上に怖い。スロー勢が凹んだらカドから一気にまくる。

### 2-2. 決まり手と展開の関係

- **逃げ**：1コースが先に回って押し切る。1マークで1号艇が先に回れれば、まず勝つ。
- **差し**：2コースが1号艇の内側を突く。1号艇が流れた（膨らんだ）時に決まる。
- **まくり**：外の艇が内の艇を外から抜き去る。STの差が大きい時、外の艇の伸びが強い時。
- **まくり差し**：内の艇がまくりに対応して開いた隙間を差す。3・5コースの得意技。
- **抜き／恵まれ**：2周目以降の逆転、転覆やFなど他艇の事故による繰り上がり。

**展開のセット読み**
- 2コースが差す → 2-1、2-3、2-4 が多い（2着は3・4コースのまくり差しか1号艇の残し）。
- 3コースがまくる → 3-4、3-5 が多い（3の外の艇が連動して差す）。1号艇は飛びやすい。
- 4コース（カド）がまくる → 4-5、4-1 が多い。1号艇が粘れば4-1。

### 4-3. 級別の外れ値（級別だけで判断しない）

- **長期欠場明けのB2**：ケガやF休みで出走回数が足りずB2になった元A級選手。実力はA級並みのことがある。**勝率とこれまでの級別を必ず確認**する。
- **事故率超過のB2**：F・L（出遅れ）・失格が多くて事故率0.70を超えた選手。実力はあってもSTで攻めにくい。
- **ボーダー付近の勝負駆け**：審査期間の終わり（4月、10月）近くは、ボーダー勝率付近の選手が級を上げる・守るために気合が入る。
  - 逆に、**事故率がギリギリの選手はSTを控えて** 走ることがある。
- **A1でもF持ち**：F2のA1はSTを大きく控えるので、1号艇でも信頼度が下がる。
- **級別は半年遅れの情報**：級別は過去の成績で決まる。**今の調子は今期の勝率と今節の成績** で見る。
- **新人**（デビュー3年未満）は、ほぼ6コース固定で動かない。1号艇に置かれるのは企画レースのとき。

### 4-4. 勝率の見方

- **勝率の差1.0以上** ははっきりした力の差。0.3以内は誤差。
- **当地勝率** が全国勝率より大きく高い選手 → 水面巧者。逆に当地で極端に悪い選手は割り引く（ただし当地の出走数が少ないなら参考程度）。
- 1コースでの1着率は選手によって大きく違う（全国平均は約53%、A1の上位は70〜80%台）。**選手個人のコース別成績** を確認する。

### 4-5. 個人の選手データについて

- 選手は約1,640人いて、成績は毎節変わるので、このノートでは選手個人の一覧は持たない。
- 予想するときに、そのレースの6人について調べる。見る項目：級別、全国・当地勝率、コース別の1着率と平均ST、F・Lの持ち状況、今節の成績、得意な決まり手。

### 4-6. スタート（ST）

| 平均ST | 評価 |
|---|---|
| 0.12以下 | 非常に速い（攻め屋。トップ級） |
| 0.13〜0.15 | 速い |
| 0.16〜0.18 | 平均 |
| 0.19以上 | 遅い（外から攻められない。インでも危ない） |

- **F（フライング）持ち**：F1だとSTを0.03〜0.05ほど控えることが多い。**F2はかなり控える**ので、イン戦でも飛ぶリスクが高い。
- F休み明けの選手は勘が戻りにくい。
- **スタート展示のST** は本番の参考になる。ただし本番の方が全体に速くなりやすい。

### 4-7. 体重

- 体重差は直線の伸びに出る。軽い選手は伸びが良い（女子選手が有利な点のひとつ）。
- 男子の体重下限を下回る選手は、調整重量（おもり）を積む。極端に重い選手は直線で不利。

## 5. 機力（モーター・展示）

### 5-1. モーター2連率

| 2連率 | 評価 |
|---|---|
| 45%以上 | エース級 |
| 38〜45% | 好機 |
| 30〜38% | 普通 |
| 30%未満 | 弱め |

- **重要な外れ値**：モーターは場ごとに年1回入れ替わる。**入れ替え直後（期初）の2連率は母数が少なく信用できない**。
- 2連率は「誰が乗ってきたか」の影響を受ける（強い選手が乗れば数字が上がる）。
- 今節（今の開催）の着順と、選手のコメント（「伸びがいい」「出足が良い」など）を重視する。

### 5-2. 展示タイム（150m換算、目安6.60〜6.90秒）

- 同じレースの中での **相対比較** が基本。場や天候が違うと比べられない。
- **トップと0.05秒以上の差** は、見て取れる差。0.10秒以上は大差。
- 展示タイムトップ艇の1着率は約29%、そのトップ艇が1コースなら約58%（古い集計）。
- **1号艇が展示ワースト** → インが飛ぶ危険サイン。**外枠の艇が展示トップ** → まくり候補。
- 手動計測の場と自動計測の場がある。手動の場は誤差が出やすい。
- 周回展示：1周タイム（ターンを含む）、回り足、直線の伸びを見る。
  - 出足：スタート直後の加速、ターン出口の立ち上がり
  - 伸び足：直線のスピード
  - 回り足：ターンのしやすさ

### 5-3. 選手コメントの使い方（2026-10-08の実戦で決めたルール）

- **コメントだけで、実力上位・展示上位の選手を3着候補から外さない。** 大村12Rの原村（展示1位タイ）と若松7Rの土屋（唯一のA級）は、悪いコメントで下げたが、どちらも舟券に絡んだ
- コメントで大きく下げてよいのは、**コメントも数値も悪いとき**（例：大村11Rの山崎は「出てない」＋展示下位＋部品交換 → 着外）
- コメントは悪いが数値は良い、またはコメントは良いが数値は悪いなど、悪い材料がどちらか一方だけのときは、**1着候補から外す程度にとどめ、2・3着には残す**
- 展示タイム1位でも、勝率の低いB級選手は過信しない（若松7Rの江藤は展示1位で着外）

### 5-4. 調整情報

- **チルト**：角度を上げる（+0.5〜+3.0）と伸びが出やすいが、ターンは流れやすい。外枠の選手のチルトアップは一発狙いのサイン。
- **部品交換**：ピストン、リング、シリンダー、キャブレター、ギアケース、キャリアボデーなど。大きい部品の交換は「足が悪いので何とかしたい」サイン。ただし交換して良くなるケースもある。
- **ペラ**（プロペラ）：選手が自分で叩いて調整する。新ペラは手探りの状態。

## 6. 水面・気象

| 条件 | 影響 |
|---|---|
| **向かい風（ホームストレッチで）** | ダッシュ（4〜6コース）の加速が生きて、**まくりが決まりやすい**。インは艇が浮いて流れやすい |
| **追い風** | **イン有利**。ただし強すぎる（5m以上）とターンで流れて、**2コースの差し**が決まりやすい |
| 横風 | ターンが乱れやすい |
| 風速5m以上 | 荒れやすい。展開が読みにくい |
| 波高5cm以上 | 腕力・体格のある選手、乗りこなしの上手い選手が有利 |
| **安定板使用** | 艇が安定する代わりに伸びが落ちる。外からのまくりが届きにくく、**イン有利** になりやすい |
| 周回短縮（3周→2周） | 逆転のチャンスが減る。1マークでの決着がより重要 |
| 潮（海水・汽水の場） | 満潮で水面が高いとイン有利、干潮で荒れることも（場による） |
| 気温・湿度 | 気温が高いとモーターの出力が落ちやすい。気温が低い冬はモーター差が出やすい |

## 7. 固いレース・荒れるレースの見分け方

### 7-1. 固いレース（1号艇から勝負できる）のサイン

チェックが多いほど固い：

- [ ] 1号艇が **A1** で、**他の5艇がB級中心**
- [ ] 1号艇の平均STが **0.15以下** で、F持ちではない
- [ ] 1号艇の当地勝率が良い
- [ ] **イン強い場**（徳山・大村・下関・芦屋・尼崎など）
- [ ] 1号艇の展示タイムが **上位**、足のコメントも良い
- [ ] 2・3号艇がSTの遅い選手か差し屋（まくれない）
- [ ] 風が弱い〜ゆるい追い風、波が穏やか
- [ ] **番組の性格**：ドリーム戦・特選・選抜戦・優勝戦の1号艇、企画レース（1号艇にA級を置く番組）

→ このとき3連単 **1-2-3、1-3-2** などの本命サイドは配当が低い（数百円台）。
→ 期待値を取るなら「1着は1号艇固定、2・3着を絞る／ずらす」こと。

### 7-2. 荒れるレース（高配当狙い）のサイン

- [ ] 1号艇が **B1・B2**、または **F2持ち**、平均STが遅い
- [ ] 1号艇が展示で足が見劣り（展示タイム下位、出足が悪いコメント）
- [ ] 2〜4号艇に **A1のまくり屋**、STが速い選手
- [ ] **カド（4コース）に攻める選手**がいる
- [ ] 前付けする選手がいて、進入が乱れる → 1コースが深いところからのスタートになる
- [ ] 向かい風が強い（3〜5m以上）、波が高い
- [ ] 荒れる場（戸田・平和島・江戸川・鳴門・桐生など）
- [ ] 実力が近い選手ばかりの一般戦の予選、女子戦、新人戦
- [ ] オッズで1号艇の人気がかなり高いのに、根拠が弱い（過剰人気）

### 7-3. 「1号艇が飛ぶ」主なパターン

1. **STで凹む**：1号艇のSTが遅れ、2コースか3コースにまくられる。
2. **ターンで流れる**：1号艇が膨らみ、2コースに差される。
3. **深い進入**：前付けで1コースの助走距離が短くなり、加速が足りない。
4. **足負け**：モーターが弱く、出足で外の艇に負ける。

## 8. 外れ値・注意すべき例外

| 外れ値 | 対処 |
|---|---|
| 期初のモーター2連率 | 信用しない。今節の着順と展示を優先 |
| 手動計測の展示タイム | 数値の小さな差を信じすぎない |
| 1号艇がF2・F休み明け | 勝率が高くても割り引く |
| 選手の当地での極端な成績（出走数が少ない） | 出走数が少ないなら参考程度 |
| 新人・初出場の場 | データが少なく、予想が不安定 |
| 3か月単位の場別1着率 | 季節で大きく動く。年間の数字と合わせて見る |
| 超高配当（3連単10万円以上） | 転覆、F、エンスト、失格などの事故絡みが多い。狙って当てるものではない |
| 歴代最高配当 | 3連単 **76万1,840円**（児島、2022年11月1日 7R） |
| 優勝戦・準優勝戦 | 予選の得点上位が内枠に入るので、1号艇の1着率が大きく上がる（場によっては7割前後） |
| 進入固定レース | 前付けがないので、枠なり前提で考えてよい |
| 欠場・返還 | 5艇立てになると、組み合わせとオッズが大きく変わる |

## 9. 買い目の考え方（資金管理）

- **合成オッズ**：買う点数が多いと、当たっても損をする（トリガミ）。点数を増やすときは、合成オッズが2倍以上になるかを確認する。
- 本命レースは **1着固定で点数を絞る**（例：1-23-234 の4点）。
- 荒れるレースは **2着・3着に1号艇を残す**（例：3-1-全、4-1-全）。1号艇は1着を逃しても、3着以内には約8割残る。
- 3連複は「着順は読めないが、3艇は読める」ときに使う。
- 1日に全部のレースを買わない。**確信度の高いレースだけ買う**（見送りも予想のうち）。
- 予算と1日の上限額を決める。取り返そうとして賭け金を増やさない。

### 13-4. 予想し直し（2026-10-08〜09 に予想した15レース）

- 15レースだけなので、たまたまの差も大きい

### 13-5. 予想のやり方（モデル導入後）

1. `predict.py` で、各艇の1着確率・3着以内確率と、確率順の2連単・3連単を出す
2. **2・3着の相手は、モデルの3着以内確率の上位から選ぶ**（モーター1位・今節好調・若手を自動で考慮）
3. 競艇日和の周回・コメントは、**モデルの順番を1つ入れ替える程度**の微調整だけ
4. 期待値（確率×オッズ）が1未満の買い目は、配分を減らすか外す

### 13-6. 期待値による「買い／見送り」判定（`predict.py` の最後に表示）

- 確率は「モデルの確率」と「オッズから逆算した世間の確率」を**半々で混ぜて**使う（モデルの過信を防ぐ）
- 買える目：3連単は**期待値1.1以上・確率2%以上**、2連単は**期待値1.1以上・確率5%以上**、期待値の高い順に**最大5点**（13-8で見直し）
- 判定：
  - 買える目がない → **⛔ 見送り**（世間とモデルの評価が同じで、配当が見合わない）
  - 買える目の合計の的中確率が10%未満 → **⛔ 見送り**（当たる見込みが低すぎる）
  - 1着本命の確率が35%未満 → 荒れやすいことを注意として表示
- 予想は `kyotei-kun/data/predictions.jsonl` に自動で記録し、`python3 kyotei-kun/tools/settle.py` で結果と照合して、**「買い判定」と「見送り判定」の成績**を集計する
- しきい値は13-8で過去の最終オッズを使って検証した。実際に買う時点のオッズでの成績は settle.py の記録で引き続き確認する
- ⚠️ オッズは締切直前まで動く。判定は**展示が出た後、締切の数分前**に出すのが一番正確

### 13-7. ボート基盤モデル v2（3年分・LightGBM、2026-10-09 夜）

### 13-8. 2・3着モデルと期待値判定の見直し（2026-10-09 夜）

**2・3着モデル（`model3.py`）**：1着の艇（と2着の艇）が決まったとき、残りの艇のどれが次に来るかを、コースの位置関係（1着の艇の内か外か、1着と2着の間か など）を入れて直接学習。3連単の確率＝v2の1着確率×2着モデル×3着モデル。

| テスト期間（6,000レース） | 旧（Harville γ0.6） | 新（2・3着モデル） | 実際 |
|---|---|---|---|
| 1-2 の確率 | 13.7% | 18.8% | 19.6% |
| 1-5 の確率 | 9.5% | 6.5% | 6.7% |
| 1-6 の確率 | 6.5% | 4.3% | 3.8% |
| 3連単 上位6点の的中 | 39.8% | **42.1%** | |

**期待値判定の検証**：公式サイトから 2026-04〜09 の1,739レースの**最終オッズ**（3連単・2連単）を取り、実際の払戻で計算。4〜6月と7〜9月に分けて、両方で安定している線を選んだ。

- 1点ずつ見ると、新モデル（市場と半々）は**期待値が高いほど回収率がきれいに上がる**（3連単：期待値0.6未満→43%、0.8〜0.9→85%、1.1〜1.2→106%、1.2〜1.4→117%）。旧モデルやモデル100%は、この並びが崩れる

**⚠️ 限界（大事）**
- 使ったのは**締切後の最終オッズ**。実際に買う時点（締切の数分前）のオッズとは違い、モデルが狙う目は締切直前に売れてオッズが下がることもある。**実際の回収率はこれより低いと考える**
- 的中は5〜6レースに1回で、配当の大きい当たりに支えられている。**連敗は普通に起きる**（10レース以上当たらないことも珍しくない）
- 学習データの進入コースは実際のレースのもの（予想時はスタート展示で代用）
- だから、settle.py で**実際に買う時点のオッズでの成績**を記録し続け、50レース程度たまったら線を見直す

- 2・3着モデルにもクセ（候補の艇のまくり率・内側の艇のST・外側の艇のまくり率、1着/2着の艇のタイプなど）を足して試した：2着の対数損失 1.3104→1.3092（わずかに改善）、3着 1.2135→1.2138（変化なし）、3連単の上位6点的中 42.2%→42.1%、**判定どおりに買った回収率 152%→136%**（4〜6月 145→123%、7〜9月 159→148%）。こちらも**不採用**
- まとめ：走り方のクセは、当てはまりをごくわずかに良くするが、オッズに対する「割安な目」を見つける力は上げない（世間もこの程度のクセは織り込んでいると考えられる）

### 13-10. 実戦（2026-10-10、締切前のオッズで判定）から学んだこと

- モデルが「割安」と見た目には、ほかの人のお金も後から入ってくる。**早い時間の「買い」は、締切前にもう一度確かめる**

**2. スクショ（周回・周り足・直線・コメント・展示のF）で判断を変えた結果**

**3. 風向きのデータのずれを見つけて直した**
- 公式ページの風向コード（is-wind1〜16）は**その場のコースに対する向き**で、学習データ（方角）とは場ごとに一定数ずれていた（24場すべて確認、`data/wind_offset.json`）。予想時の風向きが正しくモデルに渡っていなかったので `predict2.py` で修正

#### B-3. 注意

- 単勝は1着しか当てないので、**的中率は20〜25%（4〜5回に1回）**。連敗が普通に起きる
- 場ごとの条件（例：鳴門の3号艇）は件数が150〜180と少なく、たまたまの可能性が高いので採用しない
- どの狙い目も**回収率100%前後**。「確実に勝てる」ものではなく、「損が一番少ない／うまくいけばプラス」の水準

#### B-4. 予想への組み込み方
